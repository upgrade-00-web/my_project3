# Учет личных финансов

Простое desktop-приложение на Python для учета доходов и расходов.

## Возможности
- добавление и удаление операций;
- категории доходов и расходов;
- история операций в таблице;
- расчет баланса;
- аналитика по категориям;
- автоматическое сохранение в `transactions.csv`.

## Запуск
1. Установите Python 3.
2. Откройте терминал в папке проекта.
3. Выполните команду: `python finance_gui.py`
